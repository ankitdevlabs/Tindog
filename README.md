# TinDog

A landing page for a fictional dating app for dogs. Built as a front-end project to practice HTML, CSS, and Bootstrap.

## Features

- Responsive landing page with Bootstrap 4
- Navigation bar with smooth scrolling to sections
- Hero section with download buttons
- Features section highlighting app benefits
- Testimonial carousel with dog profiles
- Press logo section
- Pricing cards for different dog sizes
- Call-to-action section
- Footer with social media icons

## Technologies Used

- HTML5
- CSS3
- [Bootstrap 4](https://getbootstrap.com/)
- [Font Awesome](https://fontawesome.com/)
- Google Fonts (Montserrat, Ubuntu)

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/tindog.git
   cd tindog
   ```

2. Open `index.html` in your browser.

No build step or server required — this is a static front-end project.
